# ひろしま協働DXプロジェクト LP — 画像アセットについて

最終更新: 2026年8月29日

## 背景は画像ではなく、CSSで描いています

このLPの背景は「海面から深海へ潜っていく1本のグラデーション」です。
**画像ファイルではなくCSSで描いています。**

理由は3つあります。

1. **継ぎ目が原理的に発生しない。** 画像を section ごとに敷くと境目に線が出ますが、
   グラデーションはページ全体で1枚なので、どこにも境目ができません
2. **解像度に依存しない。** どんな画面幅・ページ丈でも破綻しません
3. **スマホ専用の背景画像が要らない。** 同じグラデーションが縦に伸びるだけです

水面から差し込む光と、漂う粒子も同様にCSS／SVGで描いています。

編集する場合は `style.css` の冒頭にある色のトークンを変えてください。

```css
--sea-0:#FBF6E9;   /*   0% 陽に照らされた水面 */
--sea-1:#DCEDF0;   /*  12% 浅瀬 */
--sea-2:#A8D3E2;   /*  26% 透ける水 */
--sea-3:#6FB2D2;   /*  42% 中層 */
--sea-4:#3D80B8;   /*  58% やや深い */
--sea-5:#1F5691;   /*  72% 深い */
--sea-6:#123A6B;   /*  86% 深海 */
--sea-7:#0A2247;   /* 100% 最深部 */
```

> **色と停止位置は `tools/check.js` も読みます。** 検証ツールは `:root` の
> `--sea-0〜7`（色）と `--sea-p0〜7`（停止位置）から実際の下地を計算するので、
> CSSを直せば判定も自動で追随します。値を別の場所に書き写さないでください。
>
> **停止位置はセクションの階層に合わせてあります**（浅瀬0〜25% / 中層25〜58% /
> 深海58〜100%）。ここがずれると、深海セクションの見出しが明るい水の上に乗って
> コントラストが足りなくなります。

## 挿絵の合成について

浅瀬・中層のカードは明るい地なので、挿絵を `mix-blend-mode: multiply` で重ね、
白い余白を消しています。深海の紺地では multiply だと沈むため、そのまま重ねて
明るさを少し補っています（`style.css` の `.vignette` 周辺）。

**挿絵を差し替えるときは、背景を白にしてください。** クリーム色や灰色にすると、
浅瀬・中層のカードでその領域だけ暗く沈みます。

## 画像を使っていない意匠

以下は画像ではなく **CSS／インラインSVG** で描いています。拡大しても滲まず、
色の変更もコードだけで済みます。

- 海の深度グラデーション、水面の光、漂う粒子
- 丸い見出しラベル（eyebrow）、番号バッジ、金の矢印
- チェックリストのチェックマーク、時期ラベルのピル
- CTAの矢印（`.chev`）

## 差し替えの基本ルール

**ファイル名・拡張子・保存フォルダを変えないでください。** HTMLとCSSが
ファイル名を直接指定しているため、名前が変わると表示されなくなります。

## 検証のしかた

ローカルで配信してから、ブラウザのコンソールで検証スクリプトを実行します。

```bash
node tools/serve.js
```

http://localhost:4173 を開き、コンソールで次を実行してください。

```js
fetch('tools/check.js').then(r=>r.text()).then(t=>{eval(t);return __checkReady()}).then(console.log)
```

`pass: true` なら合格です。落ちた場合は `failures` に理由が出ます。判定するのは
コントラスト比・横スクロール・タップ領域・画像内文字・絶対パス・画像の読み込みです。

確認する画面サイズは 1920×1080 / 1440×900 / 1100×800 / 834×1112 / 390×844 / 360×640 です。
