# ひろしま協働DXプロジェクト スクロールLP — 画像アセットについて

## 結論：画像はすべて配置済みです

このZIP内の `assets/img/` フォルダには、これまで作成してきた「ひろしま協働DXプロジェクト」LP用の画像素材（水彩・地図・海などの背景イラスト、アイコン類、船のイラスト）が **すでにすべて配置済み** です。ダウンロード後、フォルダ構成を保ったまま `index.html` をブラウザで開けば、そのまま表示されます。

以下は、今後デザインを差し替えたい場合のための「どの画像がどこに使われているか」の対応表です。ファイル名を変えずに同じ場所に上書きするだけで、HTML/CSSを一切編集せずに画像を差し替えられます。

## フォルダ構成

```
lp_scroll/
├── index.html          … ページ本体（テキストはすべてここに直接記述）
├── style.css            … デザイン（背景・カード・アニメーションのスタイル）
├── script.js             … スクロールアニメーション（GSAP優先／非対応時は自動フォールバック）
└── assets/
    └── img/
        ├── backgrounds/  … 各セクションの背景イラスト（8セクション分）
        └── icons/
            ├── ships/    … ファーストビューの船イラスト（7種）
            ├── pain/     … 「困りごと」セクションの番号バッジ・アイコン（①〜⑥）
            ├── what/     … 「できること」セクションの3枚の挿絵
            ├── benefit/  … 「メリット」セクションの5枚の挿絵
            ├── themes/   … 「募集テーマ」セクションの3つの丸アイコン
            └── flow/     … 「進め方・支援体制」セクションのハブ図アイコン（5種）
```

## 背景画像の対応表（`assets/img/backgrounds/`）

| ファイル名 | 使用セクション |
|---|---|
| `hero-bg.jpg` | 1. ファーストビュー |
| `pain-bg.jpg` | 2. こんな困りごとはありませんか |
| `what-bg.jpg` | 3. 本プロジェクトでできること |
| `benefit-bg.jpg` | 4. 参加事業者にとってのメリット |
| `themes-bg.jpg` | 5. 募集テーマ |
| `flow-bg.jpg` | 6. 進め方・支援体制（縦長画像） |
| `schedule-bg.jpg` | 7. スケジュール |
| `entry-bg.jpg` | 8. CTA（お問い合わせ） |

いずれも **文字の入っていない水彩画・地図・海のイラストのみ** の画像です。見出しやカードの文言はすべてHTMLテキストとして画像の上に重ねて表示しているため、背景画像だけを別のイラストに差し替えても文字化けやレイアウト崩れは起きません。同じファイル名・同じ横長比率（1600×900px目安、flow-bgのみ縦長）で書き出して上書きしてください。

## アイコン・挿絵の対応表（`assets/img/icons/`）

- **pain/**：`badge-1.webp`〜`badge-6.webp`（①〜⑥の丸バッジ）、`icon-1.webp`〜`icon-6.webp`（各カード右下の挿絵）
- **what/**：`icon-1.jpg`〜`icon-3.jpg`（STEP01〜03の挿絵）
- **benefit/**：`icon-1.jpg`〜`icon-5.jpg`（メリット1〜5の挿絵）
- **themes/**：`icon-1.jpg`〜`icon-3.jpg`（理美容／飲食／バックオフィスの丸アイコン）
- **flow/**：`hub-peer.png`（同じ悩みを持つ仲間）／`hub-support.png`（支援機関・業界団体）／`hub-itdx.png`（IT・DX専門家）／`hub-hiroshima.png`（広島県）／`hub-student.png`（学生・若手人材）
- **ships/**：`ship-*.webp`（ファーストビューで航行する7隻の船。デスクトップ12隻・モバイル6隻の配置に使い回しています）

## 画像を差し替える場合の注意点

1. ファイル名・拡張子・保存フォルダは変えないでください（HTML/CSS側がファイル名を直接指定しています）。
2. 背景画像はカードの文字が乗っても読みやすいよう、中央〜下部を比較的明るめ・情報量少なめにすると綺麗に見えます。
3. 差し替え後はブラウザのキャッシュが残ることがあるため、確認時はスーパーリロード（Ctrl+Shift+R / Cmd+Shift+R）をお試しください。
