# ひろしま協働DXプロジェクト スクロールLP — 画像アセットについて

最終更新: 2026年8月29日

## 背景の作り方（2026年8月28日に変更）

これまでは「1セクション＝1枚の完成イメージ画像」を背景に敷いていました。現在は
**クリームの水彩紙の下地に、水彩の装飾部品をCSSで重ねる方式**です。

変更の理由は3つでした。

1. 旧背景画像8枚のうち7枚に、カードの角丸枠・金の縁取り・数字バッジ・挿絵などの
   **UI要素が画像そのものに焼き込まれていた**（「背景は装飾のみ」というルール違反）
2. 横長1600×900の画像を縦長のスマホ画面に `background-size:cover` で敷くと
   **左右の約6割が切り落とされ**、水平線・島・灯台・来島海峡大橋が画面外へ出ていた
3. レイアウトを変えるたびに、焼き込みUIが実カードの縁からはみ出す不具合が再発していた

部品方式にしたことで、**モバイル専用の背景画像を用意する必要がなくなりました**
（同じ部品の位置とサイズだけをCSSで組み替えます）。

## 部品画像は「クリーム地を白に置き換えて」書き出してあります

装飾部品と挿絵は、元画像のクリーム色の紙地を**純白**に正規化した状態で保存しています。
CSS側では `mix-blend-mode: multiply` で重ねます。白はこの合成方法における中性色なので、

- 部品の「クリームだった余白」は下の紙に一切影響しない（＝透過しているのと同じ）
- 下地がクリームのとき、合成結果は元の水彩そのものになる

という2つが同時に成り立ちます。おかげで**余白ごと大きめに切り出してよく**、透過PNGに
する必要も、境界をぼかす加工も要りません（＝軽いJPEGのまま扱えます）。

> **差し替えるときの注意**
> 自分で部品を作って差し替える場合は、**背景をクリームではなく純白**にしてください。
> クリーム地のまま入れると、その四角い領域だけ下地が暗く沈んで見えます。

### 画像を使っていない意匠

以下は画像ファイルではなく **CSS／インラインSVG** で描いています。拡大しても滲まず、
色の変更もCSSだけで済みます。

- 紺の丸数字バッジ（`.num-badge`）
- 金の二重枠・ダイヤ付きの金罫・六角リボンの時期ラベル
- 錨のアイコン（見出しの上のラベル）
- 羅針盤（お申し込みパネルの四隅、注記の印、ハブ図の中心）
- 募集テーマの丸アイコン（はさみ／フォークとナイフ／フォルダ）
- お申し込みの3つのアイコン（羅針盤／吹き出し／望遠鏡）
- 業種のヘキサゴン6種（ヒーロー下部）
- 紙の粒（SVGの `feTurbulence`）

## 差し替えの基本ルール

**ファイル名・拡張子・保存フォルダを変えない**でください。HTMLとCSSがファイル名を
直接指定しているため、名前が変わると表示されなくなります。

位置やサイズを動かしたいときは `style.css` の末尾にある配置の一覧を編集します。

```css
.sec-benefit .d-sea { --r:-3%; --t:-6%; --w:48%; --o:.9; }
/*                     ↑右から  ↑上から  ↑幅    ↑濃さ */
```

`--l`（左から）／`--r`（右から）／`--t`（上から）／`--b`（下から）／`--w`（幅）／
`--o`（不透明度）の6つだけです。スマホ用の値は `@media (max-width:767px)` の中に
同じ形で並んでいます。

> `--b`（下から）は **px で指定**してください。`%` にすると「セクションの高さ」に対する
> 割合になるため、縦に長いセクションでは部品が画面の外まで押し出されます。

## 画像を再生成したいとき

`tools/` の中に生成スクリプトがあります（Windows PowerShell で動きます）。

| スクリプト | 役割 |
|---|---|
| `tools/build-deco.ps1` | 装飾部品とヒーロー海景を生成 |
| `tools/build-illus.ps1` | 各カードの挿絵を生成 |
| `tools/grid-overlay.ps1` | 元画像に座標グリッドを重ねる（切り出し範囲を決める用） |
| `tools/preview-deco.ps1` | 部品をクリーム地に合成した確認用シートを作る |

切り出し元は星山さんのローカルにある `LP/全体/完成イメージ` と `LP/背景画像` です。
スクリプト冒頭のパスがそこを指しているので、フォルダを移動した場合は書き換えてください。
