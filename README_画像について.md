# ひろしま協働DXプロジェクト スクロールLP — 画像アセットについて

## 背景の作り方が変わりました（2026年8月28日）

これまでは「1セクション＝1枚の完成イメージ画像」を背景に敷いていました。現在は
**クリームの水彩紙の下地に、水彩の装飾部品をCSSで重ねる方式**に変わっています。

変更の理由は3つです。

1. 旧背景画像8枚のうち7枚に、カードの角丸枠・金の縁取り・数字バッジ・挿絵などの
   **UI要素が画像そのものに焼き込まれていた**（「背景は装飾のみ」というルール違反）
2. 横長1600×900の画像を縦長のスマホ画面に `background-size:cover` で敷くと
   **左右の約6割が切り落とされ**、水平線・島・灯台・来島海峡大橋が画面外へ出ていた
3. レイアウトを変えるたびに、焼き込みUIが実カードの縁からはみ出す不具合が再発していた

部品方式にしたことで、**モバイル専用の背景画像を用意する必要がなくなりました**
（同じ部品の位置とサイズだけをCSSで組み替えます）。`assets/img/` の合計容量も
**3.12MB → 2.36MB** に減っています（旧背景8枚の約1.9MBが、装飾部品18点の
約0.61MB＋ヒーロー海景2枚の約0.67MBに置き換わりました）。

## ヒーローの海景（`assets/img/backgrounds/`）

ヒーローだけは海景そのものが主題であり、船の位置が水面の形に依存するため、
1枚絵を維持しています。

| ファイル名 | 用途 | サイズ |
|---|---|---|
| `hero-scene-wide.jpg` | 横長画面のヒーロー | 1600×772 |
| `hero-scene-tall.jpg` | 縦長画面のヒーロー | 941×1672 |

切り替えは**画面幅ではなくアスペクト比**（`max-aspect-ratio:13/10`）で行います。
タブレットの縦置き（例 834×1112）は幅が768px以上あるため、幅で判定すると
横長画像のままになってしまうためです。

どちらも、元画像に焼き込まれていた業種のヘキサゴン（6角形のアイコン列）を
除去済みです。

### 紙の粒はファイルではなくCSSで描いている

クリームの水彩紙の粒は、画像ファイルではなく `style.css` の `--paper-grain`
（SVGの `feTurbulence`）で描いています。最初はラスタ画像を4方向ミラーで
敷いていましたが、**どうしても格子状の折り目が見えてしまった**ため
差し替えました。`stitchTiles="stitch"` により継ぎ目が原理的に出ず、
ファイル容量もゼロです。

### 部品画像の重要な仕組み

各部品は **元画像のクリーム地を純白（#FFFFFF）へ正規化**して書き出してあり、
CSS側で `mix-blend-mode: multiply` を使って下地に重ねています。

白は乗算（multiply）における中性色なので、

- 部品画像の「クリームだった余白」は下地に一切影響しない（＝透過と同じ挙動）
- 下地がクリームのときの合成結果は、元の水彩そのものになる

という2つが同時に成り立ちます。**そのため部品を余白ごと大きめに切り出してよく、
透過PNGを作る必要もありません**（だからJPEGで持てて軽い）。

この正規化を行っているのは `tools/build-deco.ps1` です。元素材のパスと切り出し
矩形が全部そこに書いてあるので、部品を作り直したいときはこのスクリプトを
実行し直してください（Windows PowerShell、追加インストール不要）。

```
powershell -File tools/build-deco.ps1
```

## 装飾の位置を調整したいとき

`style.css` の「装飾レイヤー（deco layer）」の節にまとまっています。
各部品の位置とサイズは、カスタムプロパティで指定しています。

| プロパティ | 意味 |
|---|---|
| `--l` / `--r` | 左端 / 右端からの距離（%） |
| `--t` / `--b` | 上端 / 下端からの距離（%） |
| `--w` | 幅（セクション幅に対する%） |
| `--o` | 不透明度 |
| `--sx` | `-1` で左右反転 |

例：「メリット」セクションの右上の海を少し小さくしたい場合

```css
.deco-benefit .d-sea { --r:-2%; --t:-7%; --w:44%; --o:.95; }
                                          ↑ここを 38% などに変える
```

`d-mid` は**スマホ専用の中間帯装飾**です（既定は `display:none`）。
スマホではセクションが2300px級に伸びて中央が無装飾になってしまうため、
その帯だけを埋めています。

レスポンシブは同じ節の下にある3つのメディアクエリで、**同じ部品の値だけを
上書き**しています（画像の差し替えは行いません）。

- `min-width:768px` 〜 `max-width:1099px` … タブレット
- `max-width:767px` … スマホ（横構図の部品を縦構図へ組み替え）
- `max-width:389px` … 極小幅（装飾を間引いて本文の面積を確保）

## 船の配置を変えたいとき

船の座標は `tools/gen-fleet.js` に配列として書いてあります。編集して実行すると
`index.html` の該当ブロックが差し替わります。

```
node tools/gen-fleet.js
```

配置が水面に乗っているかは、次のスクリプトで背景画像の上にマーカーを重ねた
確認用画像を作って目視できます。

```
powershell -File tools/preview-fleet.ps1
```

## 画像を差し替える場合の注意点

1. ファイル名・拡張子・保存フォルダは変えないでください（HTML/CSSがファイル名を直接指定しています）。
2. 装飾部品を自分で用意する場合は、**背景をクリームではなく純白**にしてください（multiplyで白が消えるため）。クリーム地のまま入れると、その部分が下地を暗くしてしまいます。
3. 差し替え後はブラウザのキャッシュが残ることがあるため、確認時はスーパーリロード（Ctrl+Shift+R / Cmd+Shift+R）をお試しください。
