# ロゴ画像の置き場所

フッターの「主催・運営」に出すロゴをここに入れてください。

| ファイル名 | 内容 | 推奨 |
|---|---|---|
| `hiroshima-pref.png` | 広島県のロゴ | 高さ 120px 以上・背景透過PNG |
| `lts.png` | 株式会社エル・ティー・エスのロゴ（横組み） | 高さ 120px 以上・背景透過PNG |

**ファイル名は変えないでください。** HTMLが名前で直接指定しています。

置くまでは社名のテキストが代わりに表示されます（`onerror` で画像を消し、
`:has()` が外れて名前が出る仕組み）。置けば名前は読み上げ用に退き、
ロゴだけが見えます。レイアウトはどちらでも崩れません。

ロゴは白地で使う前提のものが多いため、紺のフッターに直接置かず、
白い板（`.lockup`）の上に載せています。透過PNGでも黒い文字が読めます。

## 確認しておくこと

- **広島県のロゴ・シンボルマークの使用は、県の承認が必要な場合があります。**
  公開前に県のご担当者へ確認してください。
- 「主催・運営」という表記が実際の契約関係と合っているかもご確認ください。
  委託・共催・後援では書き方が変わります。
